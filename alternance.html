01 — Alternance 2025 — 2026 AP-HP Henri Mondor GenoBioMICS

Plateforme ATLAS.

Middleware hospitalier pour le séquençage ADN, les workflows bioinformatiques et l'exploitation des données pour l'IA.

01 — Contexte

Mission.

Construire un middleware fiable, sécurisé et exploitable par les équipes médicales, techniques et de recherche.

Mon alternance porte sur la plateforme ATLAS, une solution technologique hospitalière dédiée au séquençage ADN, à l'organisation des analyses bioinformatiques et à l'exploitation des données pour l'IA.

Mon rôle est de construire le middleware central qui relie les applications, les identités utilisateurs, les autorisations, les données de laboratoire et les outils d'analyse — pour fournir une plateforme fiable, sécurisée et exploitable au quotidien.

03 — Missions & réalisations

Ce que je construis.

M.01 — Sécurité

IAM & permissions

  • Authentification OIDC avec Zitadel — PKCE, MFA, JWT, organisations
  • Sessions serveur HTTPOnly — aucun token côté navigateur
  • Autorisations ReBAC via SpiceDB (tuples de relations)
  • Autorisations ABAC via OPA (règles Rego contextuelles)
  • 6 rôles métier : admin, RH, gestionnaire, technicien, bio-informaticien, prescripteur
M.02 — Backend

Go · pattern BFF

  • Pattern BFF — le frontend ne contacte jamais directement les services tiers
  • API REST complète — endpoints protégés et publics
  • Pipeline pré-inscription : formulaire → validation admin → activation compte
  • Intégrations : Dgraph, SpiceDB, OPA, PostgreSQL, SeaweedFS, OpenSearch, Redis
M.03 — Frontend

React 19 · TypeScript

  • SPA React avec authentification par cookie de session HTTPOnly
  • Modules : portail, administration, pré-inscription RH, pipeline kanban
  • Panel admin : observabilité live, gestion utilisateurs, matrice permissions
  • Hub analyses : demandes NGS, catalogue, devis, pipeline kanban
M.04 — Données

DataLake & DataHouse

  • Stockage objet S3 via SeaweedFS — FASTQ bruts, pièces jointes, exports
  • Pipeline ETL Bronze → Silver → Gold avec DuckDB + Python
  • Tables analytiques versionnées Apache Iceberg via catalogue Nessie
  • Moteur SQL analytique Trino pour la couche Gold
  • Intégration pipelines HPC NGS : séquenceur → SeaweedFS → ETL → Iceberg
M.05 — Observabilité

Métriques & alertes

  • Collecte métriques Prometheus + persistance Redis time-series 7 j
  • Historique alertes CPU / MEM / NET et uptime health
  • Sessions utilisateurs actives en temps réel (heartbeat Redis)
  • Panel admin dédié — stats par route, latence et erreurs
M.06 — Graphe

Dgraph · CMDB

  • Modélisation des entités hospitalières — Personne, Poste, Unité, Contrat, Diplôme…
  • CMDB dédié : inventaire infra (services, clusters, pipelines IA, politiques)
  • Schéma GraphQL + DQL, seeds, outils Ratel UI / Voyager / Altair
  • Indexation full-text et audit via OpenSearch
