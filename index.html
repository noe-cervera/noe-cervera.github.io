01 — Préambule

À propos.

Je construis des systèmes solides, sécurisés — du backend Go au cluster Kubernetes de production.

Actuellement en alternance à l'AP-HP Henri Mondor (projet ATLAS / GenoBioMICS), je conçois une plateforme hospitalière cloud-native pour la génomique clinique : backend Go (BFF), authentification OIDC (Zitadel), permissions ReBAC/PBAC (SpiceDB + OPA), frontend React/TypeScript, déploiement Kubernetes sur OVH via ArgoCD GitOps, gestion des secrets Vault (OpenBao), DataHouse analytique Iceberg + Trino pour les pipelines de séquençage ADN.

Avant l'informatique, cinq années sur le terrain (menuiserie, plomberie, électricité) m'ont appris la rigueur, le rythme et la valeur d'un travail bien fait. Je transpose ça dans le code — et dans les systèmes qui tiennent en prod.
